검사결과의 각 행은 **검사항목별 기록**이다. 같은 장치가 여러 항목에 반복되므로 검사수량을 전체 행에 걸쳐 더하면 생산수량과 일치하지 않는다. 재검사 수량도 새로 생산한 수량에 더하지 않는다.

검사 합격과 출하 승인은 다르다. WO-260929-003의 합격 98대도 생산 로트 조사로 출하가 보류되어 있다.

## 6. 빈칸과 0의 의미

| 항목 | 빈칸의 의미 | 이번 데이터의 적용 |
| --- | --- | --- |
| 실제완료일시 | 아직 작업이 완료되지 않아 완료 시각이 없음 | WO-260929-003 |
| 참조검사번호 | 참조할 이전 검사가 없음 | 최초 검사에서는 빈칸, 재검사에는 최초 검사번호 입력 |
| 조치기록번호 | 해당 검사 기록에 연결된 조치가 없음 | 정상 검사에서는 빈칸, 재작업·보류에 관련된 기록에는 해당 번호 입력 |
| 품목마스터의 사양서번호·사양서개정 | 해당 품목에 별도로 연결한 제품사양서 정보가 없음 | 이번 데이터는 완제품 P-TH100에만 입력하므로 MAT-PCB-001 등 자재는 빈칸 |
| 품목마스터의 펌웨어코드·펌웨어버전 | 해당 품목에 별도로 연결한 펌웨어 정보가 없음 | 이번 데이터는 완제품 P-TH100에만 입력하므로 자재는 빈칸 |
| 측정최소·측정최대 | 숫자 범위로 기록하는 측정값이 없음 | 펌웨어 버전·외관 등은 확인결과에서 확인 |

**빈칸은 미완료·해당 없음·숫자 측정값 없음 등 항목별 이유를 나타낸다. `0`은 수량이 실제로 0이라는 뜻이다.** 예를 들어 WO-260929-003의 실제완료일시는 빈칸이지만, 포장완료 수량은 0대이다.
